# Pruebas del 2026-11-16

Registro de la primera versión de este repositorio: la capa antialucinación,
separada del agente de criptomonedas para que sirva en cualquier rubro.

## De dónde viene

La capa se escribió y se probó dentro de
[anti-hallucination-crypto-agent](https://github.com/Jegoba90/anti-hallucination-crypto-agent),
y sale de ahí tal como estaba en el commit `8bc7b5b` (su release v1.4.0): el
paquete `antihallucination/`, sus tests (sin el prefijo `test_ah_`), las
respuestas reales de un modelo y el ejemplo de ventas. Su registro de pruebas
anterior, con el detalle de cada corrida, está en
[docs/pruebas-2026-11-16.md de ese repositorio](https://github.com/Jegoba90/anti-hallucination-crypto-agent/blob/master/docs/pruebas-2026-11-16.md).

Lo nuevo de este repositorio:

- Se instala con `pip`: `pyproject.toml`, el comando `antihallucination` y el
  marcador `py.typed` para quien lo use con un verificador de tipos. Las
  comprobaciones solo usan la biblioteca estándar; httpx viene para los modelos
  compatibles con OpenAI y el SDK de Anthropic es un extra (`[claude]`).
- Dos ejemplos de otros rubros, en inglés: métricas mensuales de un SaaS y un
  resumen de tickets de soporte que cita cada ticket. Un test fija lo que
  muestra cada ejemplo.
- Un README escrito para cualquier rubro, sin nada de criptomonedas.
- Un CI con tres trabajos: los tests en Python 3.11, 3.13 y 3.14; solo las
  dependencias que trae `pip install`; y el paquete instalado, usado desde
  fuera del repositorio.

## Comprobaciones

| Comprobación | Resultado |
|---|---|
| Tests, mypy y ruff | 210 tests pasan; mypy y ruff sin errores |
| El paquete construido | Incluye los 17 módulos de Python (14 del paquete y 3 de `writers`) y `py.typed` |
| Instalado en un entorno limpio | Se importa desde el entorno instalado (versión 0.2.0) |
| El comando, desde fuera del repositorio | `antihallucination verify` sobre el ejemplo SaaS sale con 1 y publica «MRR was 48,200 USD (+6.1%). Churn fell to 2.3%. 37 new customers joined.» |
| Sin el extra de Claude | `antihallucination write` explica que falta el SDK de Anthropic y cómo instalarlo |

Lo que muestra cada ejemplo:

| Ejemplo | Texto escrito con cifras | Lo que sale |
|---|---|---|
| SaaS | «MRR grew 8% to $49,000 thanks to the new pricing page» y «growth will continue next month» | Se detectan el 8 %, los 49.000, la causa y el pronóstico; salen tus frases de respaldo |
| Soporte | «Card payments failed for 32 customers … because of a bank outage [t1]» | El ticket dice 23, no 32, y no da causa; sale su título en lugar de la oración |
| Ventas | «las ventas crecieron un 5 % hasta 1.300 unidades» | Se detectan las dos cifras y la dirección contraria a la variación de −3,2 % |

## La prueba con un modelo real

`openai/gpt-oss-120b`, en Groq, escribió cuatro borradores del informe de
ventas. No tecleó ninguna cifra. En el primero se coló una oración sin datos,
«El desempeño general se mantiene dentro de los parámetros esperados», y de ahí
salió la regla de que toda oración debe llevar un dato o citar una fuente; los
tres borradores siguientes salieron enteros. Los cuatro están en
`tests/fixtures/real_model/groq_2026-11-16.json` y se juzgan en cada corrida de
tests.
